## Como jogar
- **Espaço**: pular (também começa e reinicia o jogo)
- **Clique esquerdo**: atirar

Destrua os Lesmos para ganhar pontos (10 cada). Depois de 45 segundos o chefe **Uruca** aparece; derrote-o para vencer (+100 pontos). Encostar em um inimigo, levar tiro do Uruca ou sair da tela é derrota.

## Abrir o projeto
Abra a pasta no Unity Hub (Add > Add project from disk) usando a versão 6000.0.82f1 e carregue a cena `Assets/Scenes/SampleScene.unity`.
